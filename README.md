# Guess It India

A minimal Cloudflare Worker with a vanilla HTML/CSS/JavaScript frontend.

## Local development

Install dependencies, then start Wrangler:

```sh
npm install
npm run dev
```

The local site is normally available at `http://localhost:8787`.

## Checks

```sh
npm run typecheck
```

The health endpoint is available at `/api/health`.

## Deploy

```sh
npm run deploy
```
